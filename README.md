# 🌾 Kisan Dost AI

**Kisan Dost AI** is an AI-powered farming problem-solving system designed for Pakistani farmers.

## 🎯 Problem We Solve

Farmers often need help deciding **which crop is suitable for their land** based on different farming conditions.

Our **Farm Problem Solver** takes information such as:

- 📍 District
- 📏 Land Size
- 🌱 Soil Type
- 🌾 Season
- 💧 Water Availability

It analyzes these conditions with agricultural data and AI tools to provide a **practical crop recommendation and farming guidance**.

Along with problem solving, we also built a **Multi-Agent Farming Assistant** that helps farmers with crops, fertilizers, pests, mandi prices, and farm profit through simple **English and Roman Urdu conversations**.

## 🤖 Specialized Agents

**Agronomy Agent** — Crop & fertilizer guidance  
**Pest Doctor** — Pest identification & treatment  
**Market Agent** — Mandi price information  
**Finance Agent** — Farm cost & profit estimation  

## 🛠 Tech Stack

**Python** — Core application and farming logic  
**Flask** — Backend and web API  
**OpenAI Agents SDK** — Multi-agent system and tools  
**Groq** — LLM inference for AI responses  
**SQLite** — Agricultural dataset and application data  
**HTML/CSS/JavaScript** — Interactive farmer-friendly frontend  
**Docker** — Containerized application deployment  

## 🌱 Goal

To make agricultural decision-making **simple, data-driven, and accessible** for farmers through AI.
